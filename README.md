# 국방부 시계 수정본 (그래픽 + 도감 + 앱 패키지)

원작 「국방부 시계」를 원작자 허락을 받아 수정한 버전이다. 게임 로직과 데이터는 원작 그대로고, 화면 레이어만 추가했다.

## 추가한 것
- **픽셀 씬**: 사건 문장에 따라 장면이 바뀐다 (교육대, 생활관, 사격장, 야외 훈련, 경계 근무, 제설, 휴가, 월급날, 연락, 자기계발, 전역). 군마다 배경이 다르다 (육군 산, 해군 함정, 공군 활주로와 전투기, 해병 해안). 계절(눈·벚꽃·단풍)과 낮·저녁·밤이 사건 날짜와 문장을 따라간다. 진급하면 색종이, 사고가 나면 비가 내린다.
- **진급·사고 배너**: 계급장과 함께 화면 아래에서 올라온다.
- **효과음**: WebAudio로 직접 합성해서 음원 파일이 없다. 기본값은 꺼짐이고 "소리" 버튼으로 켠다.
- **진동**: 진급, 사고, 선택지, 전역 때 울린다. 앱과 안드로이드 브라우저에서만 동작한다.
- **복무 도감**: 입대 횟수, 군 4개, 특기 447개, 부대 132곳, 전역 도장, 최고 계급, 업적 14개를 기기에 쌓는다.
- **로그 아이콘**: 사건 줄 앞에 픽셀 아이콘이 붙는다.
- **전역 연출**: 도장 효과음, 카드 흔들림, 업적 달성 배너.
- **보안 수정**: `SECURITY-REVIEW.md` 참고.

## 구조
```
src/orig.html        원작 (수정 금지, 빌드 입력)
src/fx.js, fx.css    추가 레이어: 픽셀 장면·상태 레이어·특기 소품·컷·사운드·도감·전역 화면·다시 보기
src/dex-core.js      한 판 기록(facts)과 업적 72개 판정. node에서도 돈다
src/catalog.js       시뮬레이션으로 만든 도감 카탈로그 (사건 등급, 업적 확률). 생성물
src/sim/             시뮬레이터: extract_logic.py → sim2.js(병렬) → merge.js → gen-catalog.js
build.py             원작에 훅을 꽂아 dist/artifact.html, app/www/index.html 생성
app/                 PWA + Capacitor 래퍼
sources/mma/         병무청 모집병 특기 원자료(JSON)와 대조 스크립트
docs/                컷 후보 목록, 폐기한 480 시안
tests/               Playwright 회귀 테스트 (레포 루트에서 실행, shots/ 폴더 필요)
```

## 자주 쓰는 명령
```
python3 build.py                                   # 빌드
mkdir -p shots && node tests/test3.js              # 전체 플레이 회귀 (병사·장교 한 판씩)
python3 src/sim/extract_logic.py                   # 시뮬레이션 준비
cd src/sim && for i in 1 2 3 4; do node sim2.js 7500 part$i.json & done; wait
node merge.js && node gen-catalog.js && cd ../.. && python3 build.py   # 카탈로그 갱신
```

## 정해진 원칙
- 픽셀 해상도를 올리지 않는다. 장면 240×60, 컷 240×240 (2026-10-11 결정)
- 원작 로직과 데이터는 고치지 않고 build.py의 훅으로만 붙인다. 원작이 바뀌면 build.py가 "패치 실패"로 멈춘다
- 근무지 장면 8종은 보류 중

## 출시 경로 (싼 순서)

### A. PWA (지금 바로, 0원)
1. `app/www/` 폴더를 GitHub Pages나 Cloudflare Pages에 올린다.
2. 링크를 공유한다. 폰에서 "홈 화면에 추가"하면 앱처럼 열리고 오프라인에서도 돌아간다 (테스트로 확인함).

### B. 구글 플레이 (전역 후 권장)
필요한 것: PC, Node.js, Android Studio, 플레이 콘솔 개발자 계정 (등록비 25달러 1회, 기억 기반).
```
cd app
npm install
npx cap add android
npx cap sync android
npx cap open android      # Android Studio에서 Build > Generate Signed Bundle (AAB)
```
- 2023년 11월 이후 만든 개인 개발자 계정은 프로덕션에 출시하기 전에 테스터 12명 이상이 14일 동안 비공개 테스트를 해야 한다 (기억 기반, 출시 전에 플레이 콘솔에서 확인할 것). 친구 12명을 미리 모아 둔다.
- 스토어 등록정보: 앱 이름(국방부를 뺀 이름), 짧은 설명, 스크린샷 2장 이상, 512px 아이콘(`www/icons/icon-512.png`), 개인정보처리방침 URL(`PRIVACY.md` 공개본), 콘텐츠 등급 설문, 데이터 보안 양식("수집 없음").
- `capacitor.config.json`의 `appId`를 네 도메인 역순으로 바꾼다 (예: `io.github.아이디.mndclock`). 한 번 출시하면 못 바꾼다.
- package.json의 Capacitor 버전은 작성 시점 기준이니 `npm install` 전에 최신 메이저를 확인한다.

### C. 앱스토어 (iOS)
맥과 Xcode가 있어야 하고 개발자 등록비가 연 99달러다 (기억 기반). 맥북 구매를 보류 중이라 지금은 이 경로를 쓸 수 없다. iOS 사용자는 A(PWA)로 대응한다.
