# 시뮬레이션 재미·밸런스 점검 (2026-10-12)

`node src/sim/analyze.js 4000` (먼저 `python3 src/sim/extract_logic.py`). 선택지는 무작위로 고른다. 그래서 같은 갈림길 안에서 답별 결과 차이는 무작위 배정 실험처럼 읽을 수 있다. 다만 답마다 표본이 수십~수백 판이라 차이 0.5 이하는 잡음 범위다.

## 발견
1. 한 판 안 반복: 병사 판의 96%, 간부 판의 60%에 같은 문장이 두 번 이상 나온다. 정기휴가·체력검정은 원래 반복되는 일이라 괜찮다. 문제는 분위기 문장("저녁마다 체력단련장에서 땀을 뺐다" 16%, "사지방에서 인강" 15%, "넉가래" 15%, "동기들과 수다" 15%)이 한 판에 두 번 나오는 경우다.
2. 선택이 결과를 거의 안 바꾼다: 갈림길 64종 중 결과 점수 차이가 1을 넘는 건 진로 선택 3개(장교 지원, 다른 군 재입대, 장기복무 지원)뿐이다. 매 몇 달 고르는 능력치 집중은 병사 0.36, 간부 0.05로 사실상 차이가 없다.
   - 결과 점수: 병사는 포상휴가×2 − 사고 수 + 만기 3점, 간부는 최종 계급 순위. 돈·연애처럼 이 점수에 안 잡히는 결과는 따로 봐야 한다.
3. 긴장감이 낮다: 사건의 73~78%가 중립 사건이고 사고는 4%, 진급·좋은 일은 10~13%다.
4. 간부 판이 성기다: 수십 년을 평균 55줄로 보여 준다. 8%는 15줄 이하로 끝난다(이른 전역). 1년 넘게 아무 사건도 없는 구간이 판당 0.8번 있다.
5. 업적 쪽 밸런스(3만 판 결과): 전역 자금 2천만은 만기 병사면 거의 다 받는다. 전설 사건의 대부분은 드문 특기의 일상 업무다.
