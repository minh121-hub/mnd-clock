## 원칙별

### 1. 시스템 상태의 가시성
- 잘 됨: 복무 시계, 장면 왼쪽 위 계급·날짜, 능력치 변화량, 진급·사고 배너, 다시 보기 중 표시.
- **고침 (2026-10-12)**: 선택지가 나올 때만 화면이 따라 내려가던 문제. 이제 사건마다 따라가고, 위로 올려 읽는 중이면 끌어내리지 않고 "새 기록 ↓ / 선택지가 기다려요 ↓" 버튼을 띄운다.
- 남음: 선택 대기 중 장면 쪽 표시 없음 (2). 소리 버튼 라벨 (2, 4번 원칙과 같이).

### 2. 현실 세계와의 일치
- 잘 됨: 실제 계급장 체계, 군별 용어(직별·BX·침실), 실제 날짜 흐름.
- 남음: 로그 줄 앞 픽셀 아이콘의 뜻을 어디서도 설명하지 않는다 (1).

### 3. 사용자 통제와 자유
- 잘 됨: 속도 4단계, 멈춤, 다시 보기와 "지금으로", 컷은 Esc·바깥 클릭·버튼으로 닫힘, 도감 초기화는 확인을 거친다.
- **스킵**: 한 번 누르면 남은 선택이 전부 무작위로 정해지고 되돌릴 수 없다 (3).
- **진행 중 "다시 입대하기"**: 위쪽 입대 버튼 라벨이 "다시 입대하기"로 바뀌고, 누르면 진행 중인 판이 확인 없이 사라진다 (3).
- 선택지가 뜨면 첫 번째 답에 키보드 포커스가 가서 Enter·스페이스 오입력 여지가 있다 (1).

### 4. 일관성과 표준
- "전설": 사건은 흔함·보통·희귀·전설, 업적은 일반·도전·난관·전설. 같은 단어, 다른 기준 (2).
- 같은 조작 줄에서 멈춤은 동작을, 소리는 상태를 라벨로 쓴다 (2).

### 5. 오류 예방
- 스킵·재입대 확인 없음 (3, 위와 같음).
- 자동 체크박스가 멈춤 버튼에 붙어 있다. 켜지면 다음 선택부터 무작위로 넘어간다 (2).

### 6. 기억보다 인식
- 다시 보기는 첫 안내가 사라진 뒤엔 줄이 눌린다는 시각 단서가 없다 (2).
- 능력치가 무엇에 쓰이는지(체력→체력검정 등)는 맨 아래 설명 문단에만 있다 (1).

### 7. 유연성과 효율
- 잘 됨: 속도, 자동, 스킵, 다시 보기의 ◀ ▶.
- 남음: 키보드 단축키 없음 (스페이스 멈춤 등) (1).

### 8. 미학적이고 미니멀한 디자인
- 첫 화면: 제목·설명 → 픽셀 장면 → 큰 시계 → 군·신분 선택 → 입대하기. 시작 버튼이 1,213px 아래 (3).
- 플레이 중 고정 영역 29% (1).
- 전역 화면이 증서·이번 판·통계·갈림길·비교·동기·공유 7구역으로 길다 (1).

### 9. 오류 인식·진단·복구
- 잘 됨: 복사 실패 시 "선택해 두었어요, 길게 눌러 복사하세요"로 안내.
- 남음: 저장소 차단 시 무음 실패 (2).

### 10. 도움말과 문서
- 데이터 출처와 한계 설명은 충실하다.
- 처음 하는 사람용 "이렇게 노는 거야" 3줄 안내가 없다. 자동·스킵·다시 보기 설명이 폰에서 안 보이는 title 속성에만 있다 (2).
